[2] General: Fixed =called-interactively-p= (added required ='any=
argument), =byte-compile-file= (removed obsolete ='load= argument),
=buffer-substring= as obsolete generalized variable (replaced with
=delete-region= + =insert=).  Added =(require 'warnings)= to silence
free-variable warning.  Bumped =Package-Requires= from Emacs 25.1 to
26.1 (code uses =if-let*=).

[3] Packaging: No deprecated references found.  The =Package-Requires:
((emacs "25.2"))= in the example template is illustrative, not a claim
about the handbook's code.

[4] Pattern matching: Replaced obsolete =labels= with =cl-labels= and
=loop= with =cl-loop= in =with-dict= and =with-plist-vals= code
examples.

[5] Optimization: Reflowed =bench= docstring (was wider than 80
characters).  Replaced bare CL accessors =second=/=third=/=fourth=
with =cl-second=/=cl-third=/=cl-fourth= in =bench-multi= and
=bench-multi-process-results=.  Fixed =byte-compile-file= 2-arg
calling convention in =bench-multi-lexical=.

[6] Binding: The keymap API additions (Emacs 29) were placed under
General rather than Binding, since the Binding section covers variable
scope, not key bindings.

  =https://github.com/emacs-compat/compat=,

  Info manuals, and the Elisp "Native Compilation" and Emacs "Fetching
  Package Sources" manual nodes.  The Emacs 31 "User Lisp Directory"

  yet published (the node URL 404s), so no link was added.

  landscape section's CUSTOM_IDs and ToC drawer match =org-make-toc='s
